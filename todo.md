# Update checklist

- [ ] Compare current implementation with original language, typography, content, and page structure.
- [ ] Identify and fix the user-reported visual or runtime error.
- [ ] Match original font loading and typography metrics.
- [ ] Add scroll reveal, parallax, and hover animations while respecting reduced motion.
- [ ] Verify all routes on desktop and mobile.
- [ ] Save a new checkpoint and push the update to GitHub.
