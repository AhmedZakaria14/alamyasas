# Original font inspection

The reference site exposes Montserrat weights 100–900 and Inter weights 100–900 through its loaded font declarations, plus Font Awesome and Elementskit icon fonts. The visual headline and body proportions most closely align with Montserrat for display and Inter for supporting UI/body text. The current clone uses DM Sans/Manrope, so the update should switch to Montserrat/Inter to better match the original.
